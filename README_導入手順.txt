建物調査アシスト Ver.0.6

GitHubリポジトリ building-survey-assist のルートに、このZIP内の6ファイルをすべてアップロードし、既存ファイルを置き換えてCommit changesします。
公開URLは以前と同じです。iPhoneはネット接続時にSafariでページを開き、Ver.0.6表示を確認してから機内モードで再起動してください。古い画面ならSafariの再読み込みを行ってください。

CAD作図：始点タップ→次の角をタップ→実測長さ(m)入力→この辺を確定、を繰り返します。直角固定は画面の水平・垂直方向にスナップする簡易機能です。境界離れ寸法は辺ごとの記録のみで座標拘束しません。

重要：正式な測量成果・建物床面積算定には使わないでください。SIMA出力とDXFのWingneo取込互換性は未検証です。

データは端末内に保存しますが、アップデート前後はJSONバックアップを取得してください。
